This repository contains a modular PHP-based payroll system developed as an academic project.

---

## 📌 Overview

The system implements payroll processing with business rules for dynamic work schedules, attendance calculations, and payroll computation logic.

It models core HR and payroll workflows such as employee management, time tracking, leave handling, and salary computation using a feature-based modular structure.

---

## ⚙️ Key Features

- Dynamic work schedule handling  
- Attendance tracking and computation  
- Rule-based payroll calculation logic  
- Overtime, deductions, and allowances processing  
- Leave and holiday management  
- Employee, department, and job role structure  

---

## 🧩 Structure

Feature-based modular organization:

- attendance  
- payroll  
- employees  
- work-schedules  
- overtime-rates  
- deductions  
- allowances  
- leaves  
- holidays  
- departments  
- job-titles  
- settings  
- cron-jobs  
- database  
- includes  

---

## 🔄 Execution Model

The system does not use a framework or formal application entrypoint.

Execution is handled through:
- Direct PHP script execution  
- Modular include-based composition  
- Cron-based background processing for scheduled tasks
